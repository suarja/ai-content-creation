# AI Content Creation

Agent skills for AI-driven content creation, for Claude Code and Codex. Each plugin is a
complete, tested workflow you can hand to your coding agent.

## Plugins

### [explainer-motion](./plugins/explainer-motion) — mascot explainer videos

Vertical explainer and app-promo videos: a mascot that changes pose on every phrase,
word-by-word captions and UI cards synced to a voice-over, rendered from HTML.

## Install

Claude Code:

```bash
/plugin marketplace add suarja/ai-content-creation
/plugin install explainer-motion@ai-content-creation
```

Codex:

```bash
codex plugin marketplace add suarja/ai-content-creation
codex plugin add explainer-motion@ai-content-creation
```

Then ask your agent for what you want to make; the plugin's skills take it from there.
